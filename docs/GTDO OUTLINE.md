Version: 1.0

---

# Purpose

This outline defines the long-term architectural organization of the GTDO repository.

GTDO is organized around a single central question:

> **How should training data, computational responsibilities, computational units, and AI computation be organized according to explicit goals?**

The outline serves as:

* repository constitution;
* navigation guide;
* long-term research roadmap;
* article classification standard;
* extension policy.

All new GTDO articles should be mapped into this outline before becoming part of the repository.

If a new topic does not fit naturally, the outline should be updated first.
